# Zheng Wang — Security Researcher

Red Team Security Researcher at Shopee / Sea Group, Singapore (previously Tencent Security Xuanwu Lab).

- Focus: fuzzing & automated vulnerability discovery, browser / JavaScript-engine security (V8, WebKit, SpiderMonkey), WebAssembly & JIT compilers, Linux kernel and binary security, CEF/Electron application security, security of AI-mediated browser workflows.
- 30+ CVEs disclosed across Chromium/V8, Safari/WebKit, Firefox/SpiderMonkey, the Linux kernel, and Nginx Njs.
- Talks: Black Hat (USA '24, Europe '23 & '25, Asia '23), DEF CON 31 Main Track.
- Academic: co-author, *Beyond Running Code: Rubric-Driven Agentic Artifact Evaluation* (ICSE 2027, [arXiv:2602.02235](https://arxiv.org/abs/2602.02235)); PC member, LLMSC 2026 & 2027.
